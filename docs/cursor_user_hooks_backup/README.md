# Cursor Hooks 备份说明

**现行权威 = 项目级**（已进仓）：

- `AutoExport/.cursor/hooks.json`
- `AutoExport/.cursor/hooks/*.py`

本目录保留脚本副本，便于对照；日常以项目级为准。

用户级 `~/.cursor/hooks.json` 已清空（防双重催报）。旧用户级配置备份在本机：
`~/.cursor/hooks.json.disabled_after_project_*`

其他电脑：clone/pull 本仓后 Reload Cursor，打开 Settings → Hooks 应看到 **Project config** 下 3 条。
