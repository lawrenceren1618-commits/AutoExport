# 发货项目目录（Shipments）

每一票发货 = 一个项目文件夹。

## 命名

{订单号}_{店铺代码}_{出货日期YYYYMMDD}_{条数}

条数未知时可用 TBDstrips 或 NNNCTN（箱数占位），确认后改名。

## 子文件夹

| 子文件夹 | 性质 |
|----------|------|
| 订单表 | **生成**（固定订单模板） |
| 出货表 | **生成** |
| 货代入库贴下单表 | **生成** |
| 报关资料表 | **生成** |
| 产品标签 | 自行调用/引用 |
| FBA外箱贴 | **你后续更新** |
| 货代入库贴 | **你后续更新** |
| _来源归档 | 历史样例/辅助表（采购、模板、信息表等） |

总表仍在 ../00_Master_Reference/，不按发货拆分。
