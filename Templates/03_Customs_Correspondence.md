# ③ 报关单据 — 字段对应关系

> **独立文档**：只对应「报关资料」（报关地/发票/装箱单/合同等）。  
> **禁止**与工厂订单字段表、货代下单表混用。  
> 单表变更映射：[`Table_Field_Change_Maps.md`](Table_Field_Change_Maps.md) · [`Scripts/table_field_maps.json`](../Scripts/table_field_maps.json)  
> **适用范围：后续所有发货票**（不限本票 C26079）。

状态：术语与 1039 规则已校准（2026-07-21）；等 FBA 外箱贴后再生成当票文件。

---

## 0. 术语（强制 · 防混淆）

| 称呼 | 指什么 | **不是**什么 |
|------|--------|--------------|
| **抬头** | 报关单证**表内**「生产销售单位」等**统一经营名称**（海关常用义） | ❌ 不是文件名 |
| **文件名** | `.xlsx` 磁盘文件名（变更项之一） | ❌ **禁止**称作「抬头」 |
| **内部法律主体** | C04=许昌畅选… / C07=易尚…（订单归属、内部口径） | ❌ 不等于表内抬头格必填字 |

> 口语里有人把文件名里的「畅选+波丽丝」也叫抬头 → **本项目禁用该用法**，一律说「文件名」。

---

## 1. 全局报关写法（所有后续票）

### 1.1 C04 / 1039（桌布主路径）

| 位置 | 写什么 |
|------|--------|
| **表内抬头**（生产销售单位等单元格） | **许昌波丽丝贸易有限公司**（波丽丝） |
| **文件名** | 按已验证样例习惯，可含 **`畅选+波丽丝`** + 日期/仓/箱数/FBA 等（**叫文件名，不叫抬头**） |
| **内部法律主体**（仅内部/订单语境） | **许昌畅选贸易有限公司**；**不**填进表内抬头格；工厂订单页眉仍不印畅选 |
| **征免** | **不退税，只免征** |
| HS | 桌布默认 **6302539090** |

### 1.2 C07

| 位置 | 写什么 |
|------|--------|
| 表内抬头 | 以已验证 C07 样例为准（易尚电子商务有限公司等） |
| 文件名 | 按该票样例命名，**不称抬头** |
| 征免 | 若同属 1039：**不退税，只免征**（与 C04 一致，除非当票另示） |

### 硬性规则

1. **抬头 = 表内生产销售单位统一名称**；C04/1039 下固定为 **波丽丝**。  
2. **文件名 ≠ 抬头**；文件名可出现「畅选+波丽丝」字样，仍只叫文件名。  
3. 勿把波丽丝写进订单/出货/货代表；勿把「畅选」法律全称填进报关**表内抬头格**。  
4. 金额正算反算；严禁采购底价当报关价。

## 3. 表内只变更这些（全局）

| 变更项 | 勾稽 |
|--------|------|
| **文件名**（不称抬头） | 一仓一文件；可含畅选+波丽丝等 |
| **件数** = **箱数** = **总件数** | = 该仓全部箱数 |
| **成交数量** | 该仓条数口径 |
| **单价** / **货值** | 正算反算 |
| **净重** = **总净重** | 该仓合计 |
| **总毛重** | 该仓合计 |

其余（含**表内抬头=波丽丝**、HS、免征等）为不变项，除非当票另示。
