# ② 货代下单表 — 字段对应关系

> **独立文档**：只对应「货代入库/下单模板」。  
> **禁止**与工厂订单字段表、报关单据混用。  
> 模板来源：优先你上传到 `1_Input_Raw/02_Freight_Forwarder/` 的表格。  
> 若操作无法继续而全局搜索到候选：须你先归类确认为本类后，方可写入/调用/参考（见 `.cursorrules` §0.1）。

状态：框架已建；**列级映射待你上传货代下单模板后填满。**  
前置条件：亚马逊入库货件创建并分配**具体仓库**后，再填仓库头信息（此前可只备明细草稿）。  
终审：草稿须与沉淀库交叉对照通过后再作为最终货代表输出（见 `.cursorrules` §1.2）。

---

## 1. 与订单主体的关系（填写前先对齐）

| 内部主体 | 品牌 | 店铺 / FNSKU | 货代表中通常体现 |
|----------|------|--------------|------------------|
| C04 畅选（页眉仍可能显示易尚体系信息时，以品牌/店铺为准） | WIGENIUS | C04 店 FNSKU | 品牌、海外订单号(FBA)、reference ID |
| C07 易尚电子商务 | Dressmaker | C07 店 FNSKU | 同上 |

### 硬性规则

1. **不得**因「产品规格相同」把 C04 的 FNSKU 填进 C07 货件，反之亦然。
2. **装箱信息**（箱数、单箱条数、外箱长宽高、毛重等）可从 `01` 已确认结果引用；若发现同品同牌存在多套条数/包数，按 `.cursorrules` §1.1 **先汇报由你确认**（一般倾向最新下单日期），确认前不写入货代表。
3. 仓库代码、FBA 地址、货件号：**等你提供入库货件信息后再写**；未提供时标记「待入库货件」，不要用其它批次仓码顶替。

## 2. 本类包含的单据

| 子类型 | 说明 | 上传目录 |
|--------|------|----------|

订单/出库、报关 → 见 `01` / `03`。

## 3. 从「已确认订单/出库」→ 货代表建议映射（仅货代列）

| 来源（01 已确认） | → 货代下单表（常见列名，以你上传模板为准） | 是否可暂空 |
|-------------------|---------------------------------------------|------------|
| 品牌（WIGENIUS / Dressmaker） | 品牌 | 否 |
| FNSKU / 产品标签 | 与模板「海外订单号/货件号」区分：货件号等入库后再填；FNSKU 按模板实际列 | 货件号可暂空 |
| 订单编号 | reference ID（或模板中的客户参考号列） | 按模板 |
| 中/英文品名（由规格生成） | 中文品名 / 英文品名 | 否 |
| 单箱条数 | 单品数量 | 否 |
| 箱数 | 箱数 | 否 |
| 外箱长×宽×高 | 长/宽/高(CM) | 有则填 |
| 毛重 | 毛重列（若模板有） | 有则填 |
| HS（桌布默认规则见 `.cursorrules`） | HS CODE | 按模板是否要求 |
| 仓库代码 / 收件地址 / FBA 货件号 | 表头仓库与地址区 | **待入库货件** |
| 申报单价 | 单价 | 敏感；按你是否提供申报价 |

**不填入本类**：报关合同全套、境内货源地法律文书、工厂页眉审核栏等。
