# 长任务通报闸门（>2 分钟）

## 规则（强制）

执行任一连贯任务（含 Shell、云端 API、migration、安装依赖、大文件处理、等待审批）时：

1. **预计或已耗时超过约 2 分钟仍无明确完成结果** → **立即向使用者通报**，不得静默重试或空转。  
2. 通报须含：  
   - 正在做什么  
   - **当前困难点**（卡在哪：审批、缺密钥、网络、DDL、工具无响应等）  
   - 已尝试次数 / 已排除项（简述）  
   - **可选下一步**（2–4 条，由使用者拍板）  
3. 通报后 **停**，等使用者决定再继续。  
4. 禁止：同一失败路径连续盲目重试超过 2 轮且不汇报。

## 与既有闸门

- 不替代 error-confirm-gate / Gate HX / H01。  
- 本闸门管「耗时与卡住」；业务歧义仍走 error-confirm-gate。

## 沉淀键

`Scripts/settled_knowledge_db.json` → `confirmed_defaults.long_task_report_gate`
