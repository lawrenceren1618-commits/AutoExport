## 0. 填表总原则（全局）

| 原则 | 说明 |
|------|------|
| 只改变更项 | 新发货计划：版式/列标题/合并骨架不变，只改变更字段与**行数** |
| **行数不固定** | **禁止**按固定行数套表。订单上半 / 出货明细行数 = 本票 **产品种类数** |
| **种类定义** | **尺寸 + 颜色** = 一种。同尺寸同颜色下，2/6/10…条装条数**合并为一行** |
| 出货行数来源 | **严格跟订单上半总表**（有几行出货就几行；不是另算一套） |
| 行高 ≠ 行数 | 行**高**在同一数据区内保持一致、完整展示；行**数/行内容**随种类变化，不做条数统一 |
| 合并单元格 | 严格参照该表已验证模板（出货：C04-2615 系）；纵合范围随当票行数伸缩 |
| 不得擅自删列 | 空列可留空，不删 |

### 0.1 种类合并示例（已确认）

下半/标签可细分包规，但上半与出货**只保留一行**：

| 细分（下半 / 不进上半·出货） | 条数 |
|------------------------------|------|
| 60X102inch · 白 · 2 条装 | 500 |
| 60X102inch · 白 · 6 条装 | 8000 |
| 60X102inch · 白 · 10 条装 | 1500 |
| **上半 / 出货合计行** | **60X102inch · 白 · 10000**（一行） |

### 0.2 尺寸名书写（canonical · 纠正）

| 正确（表内优先） | 错误 / 别名（读取时可认，写入宜纠正） |
|------------------|----------------------------------------|
| `60X102inch` | `60*102inch`、`60*102英寸`、`60x102英寸` |
| `60X126inch` | `60*126…`、`…英寸` |
| `70X120inch` | `70*120…`（注意是 **70** 不是 60） |
| `60X84inch` | |
| `90 inch round` | `90圆`、`90寸圆`、`90英寸圆`（标签夹名仍可用 `90圆`） |

规则：表内用英文 **`inch`**，不用「英寸」；尺寸连接符优先 **`X`**（大写），不用 `*`；圆桌用 `90 inch round`。短码↔全称见 `canonical_schema.json` → `size_shortcode_map`。

## 1. 订单表（`订单表/*.xls`）

### 1.1 结构

| 区段 | 粒度 | 行数如何定 |
|------|------|------------|
| 页眉 | 公司英文抬头 | 固定骨架 |
| 元数据 | EF 长号、下单日期、**交货日期** | 变更字段 |
| **上半总表** | **仅尺寸 + 颜色**；同色同尺寸多包规合并 | **= 种类数**（本票 11，他票可增减） |
| **下半装箱明细** | 尺寸 + 颜色 + 条数/包 + **FNSKU** + 箱规 | **= FNSKU/包规行数**（本票 23） |

### 1.2 不变项

- 两段式版式；上/下半列标题；「装箱单明细」「合计」「制单/审核」标签  
- 上半不出现 FNSKU / 条数/包 / 箱规列  
- 下半才出现 FNSKU 与装箱列  

### 1.3 变更项

- 上半行数、下半行数  
- `order_code`、`order_date`、`delivery_date`  
- 品名、克重、各行尺寸/颜色/数量  
- 下半 FNSKU、包数/箱、箱数、条数、内外箱  
- 合计条数/箱数、制单人  

### 1.4 列 → canonical

| 区 | 表列 | canonical key | 变更? |

## 2. 出货表（`出货表/*-U-*.xlsx`）

### 2.1 号段与文件名

| 项 | 规则 |
|----|------|
| 短号 | `{店铺}-{YY}{NN}`（年缩写 2026→26；NN=本店本年出货票序） |
| 表内「客户及订单号」 | **仅短号** |
| 文件名 | `{短号}-U-{交货年月日}.xlsx`；**U = USA** |
| 序号基准（用后递推） | 见 `Scripts/outbound_short_seq.json` |

### 2.2 不变项

- 标题「发货单」；标签文字（发货日期/客户及订单号/订单数量/业务员/合计）  
- 9 列表头（不删列）：品类、重量、尺寸、颜色、数量、所属订单、所属仓库、备注、目的地  
- **无 FNSKU 列**  
- 合并**模式**（参照 C04-2615）：标题横合；品类/重量/所属订单/目的地纵合——**跨行数 = 当票种类数**（不固定 11）  
- 明细 = 订单**上半**逐行拷贝（已按尺寸+颜色合并包规）  

### 2.3 变更项

- **数据行数** = 订单上半行数 = 尺寸×颜色种类数（**不固定**；本票恰为 11）  
- 发货日期、短号、总条数、业务员  
- 每行尺寸（写 canonical）/颜色/数量；品类；克重  
- 目的地（默认 US）；备注；所属订单/仓库通常空  

### 2.4 列 → canonical / 来源

| 表列/位 | canonical / 语义 | 来源 | 变更? |
|---------|------------------|------|-------|
| 订单发货日期 | `ship_date` | 订单 **`delivery_date`** | 变更 |
| 客户及订单号 | `outbound_short` | 短号递推 | 变更 |
| 订单数量 | `qty_strips` 合计 | 订单上半合计 | 变更 |
| 业务员 | `sales_person` | 默认任胜国 | 变更 |
| 产品品类 | `product_name_zh` | 订单上半 | 变更 |
| 重量 | `gram_weight` | 订单 | 变更 |
| 尺寸规格 | `size` | 订单上半 → **规范为 canonical** | 变更（行） |
| 颜色 | `color` | 订单上半 | 变更（行） |
| 数量 | `qty_strips` | 订单上半（含各包规合计） | 变更（行） |
| 所属订单 | — | 默认空 | 通常空 |
| 所属仓库 | `warehouse_code` | 默认空（工厂直发） | 通常空 |
| 备注 | — | 可空 | 变更 |
| 目的地 | `destination` | 默认 `US` | 变更 |

## 3. 表间映射（订单 → 出货）

```text
订单.delivery_date          → 出货.ship_date / 文件名日期
订单.order_code (EF)        → PROJECT 映射；不出在出货短号格
短号规则(店铺+年+票序)       → 出货.outbound_short / 文件名
订单.上半 每行(size,color,qty) → 出货.明细同行（行数=种类数，包规已合并）
订单.上半合计                → 出货.订单数量 / 合计
订单.gram_weight / 品名     → 出货.重量 / 品类
订单.下半 / FNSKU / 条数包  → ✗ 不进入出货表
size 写入                   → canonical（X + inch）
```

### 4.3 变更项（仅这些）

| 项 | 单元格/口径 | 规则 | 来源 |
|----|-------------|------|------|
| 仓库代码 | E3 | 仓码 | FBA 外箱贴 |

| 箱 | C15 | 该仓总箱 | 外箱贴统计 |
| 中英文品名 | D15/E15 | 常「桌布 / table cloth」 | 样例 |
| 单箱数量 | F15 | **`floor(总条÷总箱)`** | 仓汇总 |
| 单价 | G15 | 分仓正算反算单价 | 总表 1039 |
| 图片 | S15 + media | 样例 `DISPIMG`；**save 后强制 reinject**（缺 media=图丢失，AWD/FC 均须） | 模板 |
| 销售链接 | T15 | C04=`https://www.amazon.com/dp/B0CCRKDW1K?th=1`；C07=`https://www.amazon.com/gp/product/B0FNVMX537` | 沉淀库 |
| 文件名 | — | 含仓码/箱数 | — |

### 4.4 单价（与报关共用算法；货代表不写总价列）

1. `raw = Σ(箱 × 总表1039每箱单价)`  
2. `单价 = round(raw / 该仓总条数, 2)` → 写入 G15  
3. 报关侧货值另做正算反算 + 误差率闸门（[`Amount_Weight_Reconcile.md`](Amount_Weight_Reconcile.md)）  
4. **货代表箱重尺固定 16**，与报关毛净重算法分离  

### 4.5 → 多表

```text
FBA外箱贴(仓)     → 货代 E3/E8/A15/B15
该仓箱数合计      → 货代.箱 C15
floor(条÷箱)      → 货代.单箱数量 F15
分仓单价          → 货代.单价 G15
客户单号/箱重尺/HS/品牌三列 → 固定，禁止被追踪码或总表箱规覆盖
样例图片          → S15 + xl/media reinject
```

## 5. 报关资料表（已确认 · C26079-A 已出草稿）

样板：历史「畅选+波丽丝…市场采购数据」。本票草稿：`Shipments/EF-C26079-…/报关资料表/`。本票 **C04**。

### 5.1 术语 + 1039 主体（**全局 · 所有后续票**）

| 称呼 | 含义 | C04/1039 取值 |
|------|------|----------------|
| **抬头** | 表内「生产销售单位」等统一名称 | **许昌波丽丝贸易有限公司** |
| **文件名** | `.xlsx` 名；**禁止叫抬头** | 可含 `畅选+波丽丝`+日期/仓/箱数等 |
| **内部法律主体** | C04 归属（非表内抬头格） | **许昌畅选贸易有限公司** |

征免：**不退税，只免征**。

勿把「文件名」说成「抬头」，以免与生产销售单位混淆。

### 5.2 不变项（表内骨架）

- 五 sheet 结构与列标题  
- **表内抬头** = 波丽丝（生产销售单位等）  
- HS、包装种类、征免=**免征**  
- 除 §5.3 外的单元格  

### 5.3 变更项（**仅这些**）

| 变更项 | 说明 |
|--------|------|
| **文件名** | 分仓/箱数等；可含畅选+波丽丝；**不称抬头** |
| **件数** / **总件数** | = 箱数 = 该仓全箱 |
| **成交数量** | 该仓条数 |
| **单价** / **货值** | 正算反算 |
| **净重** / **总净重** | 相等，该仓合计 |
| **总毛重** | 该仓合计 |

### 5.4 → 多表

```text
表内抬头(生产销售单位)  → 波丽丝（不变策略）
文件名                  → 可含畅选+波丽丝…（变更；≠抬头）
内部主体畅选            → 仅内部/订单语境；不进表内抬头格
FBA分仓箱数             → 件数=总件数=箱数
FBA分仓条数             → 成交数量
分仓净毛重              → 净重=总净重；总毛重
申报单价/货值           → 正算反算
```
