# 货值 / 毛净重：规格汇总 ↔ 分仓汇总对照（强制工作记录）

> 确认日：2026-07-22（误差率闸门同日确认）  
> 适用：所有后续发货票的货代 / 报关金额与毛净重  
> 本票实测：`2_Processed_AI/drafts/C26079-A_amount_weight_reconcile.json`

## 1. 两种算法（必须都算、都留档）

### A. 规格汇总（对照基准）

对当批已发（或计划）的每个 FNSKU / 规格行：

```text
行货值 = 该规格总箱数 × 总表「1039每箱报关单价/箱」
行净重 = 该规格总箱数 × 总表「每箱净重/KG」
行毛重 = 该规格总箱数 × 总表「每箱毛重/KG」

规格汇总货值 = Σ 行货值
规格汇总净重 = Σ 行净重
规格汇总毛重 = Σ 行毛重
```

### B. 分仓汇总（落表口径）

对每个目的仓：

```text
raw_货值 = Σ(该仓内各规格箱数 × 对应每箱单价)
单价_USD = round(raw_货值 / 该仓总条数, 2)
落表货值 = round(单价_USD × 该仓总条数, 2)   ← 正算反算；以条数×单价回写为准

落表净重 = round(Σ(该仓箱数 × 每箱净重), 2)
落表毛重 = round(Σ(该仓箱数 × 每箱毛重), 2)
```

五仓（或多仓）落表货值合计 = Σ 各仓落表货值。

## 2. 误差率闸门（下一步依据 · 强制）

以 **A（规格汇总）为分母** 计算相对误差：

```text
误差率 = |B − A| / A × 100%
（若 A = 0：仅当 B = 0 视为通过，否则视为超限须确认）
```

对 **货值、净重、毛重** 三项分别计算。

| 误差率 | 判定 | 动作 |
|--------|------|------|
| **≤ 1%** | **正常误差** | **无需向使用者报告**；继续落表（货值用 B；毛净重用 B） |
| **> 1%** | **异常** | **阻断自动往下**；必须人工确认后方可继续生成/Gate |

说明：

- 分仓单价四舍五入导致的货值差额，通常远小于 1%（本票 C26079-A 货值误差率 ≈ **0.073%** → 正常）。  
- 毛净重在算法一致时应接近 0；若 >1% 几乎必为数据错配，须确认。  
- **落表仍以 B 为准**；A 只作对照与误差率分母。

## 3. 落表权威

| 字段 | 权威口径 |
|------|----------|
| 货代/报关 **货值、单价** | **B 分仓正算反算** |
| 货代/报关 **净重、毛重** | **B 分仓 Σ(箱×每箱重)** |
| A 规格汇总 | 必算、必写入对照文件；≤1% 不打扰使用者 |

## 4. 每次生成货代/报关后的强制动作

1. 算 A（货值、净重、毛重）与 B（分仓明细 + 合计）。  
2. 算三项误差率；写入对照文件。  
3. **仅当任一项误差率 > 1%** 时向使用者汇报并等待确认。  
4. 落盘：  
   - 当票：`拆单比对/{腿ID}_amount_weight_reconcile.md` + json  
   - 汇总：`2_Processed_AI/drafts/`  
5. 脚本：`Scripts/09_generate_freight_customs_drafts.py`。
